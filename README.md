# SmartSight

AI Assistant for the Blind

## Description

SmartSight provides blind and vision impaired users with AI tools including OCR, facial recognition, and interactive image analysis to answer specific questions about the world. It also features an obstacle detection and warning system and leverages both edge and cloud computing platforms.

## Getting Started

### Dependencies

* Client program runs on Windows 10/11 with NVIDIA CUDA GPU.
* Server program runs on PiOS Debian 11 (Bullseye)

### Installing

* Configure server as USB gadget
* Download and install the Acer Incorporated USB Ethernet/RNDIS Gadget windows driver (available here: https://www.catalog.update.microsoft.com/Search.aspx?q=Acer%20Incorporated.%20-%20Other%20hardware%20-%20USB%20Ethernet%2FRNDIS%20Gadget)
